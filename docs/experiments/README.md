# Public experiment index

The public tree records only the three complete development cases summarized
in [the latest iteration](../iterations/2026-09-18-v0.1.0-alpha.2.md).

Raw JSON receipts, camera frames, videos, RPC events, asynchronous usage
snapshots, and infrastructure-failure traces belong in private, access-
controlled evidence storage. They are deliberately not duplicated here:
they contain operational metadata and are not required to understand the
public method contract.
