# Research collaboration

Proposals, not enabled features or performance guarantees:

1. **Subtask authority:** bounded direct takeover with explicit entry/exit and progress checks; do not automatically return control to a weak policy after every correction.
2. **Closed-loop primitives:** grasp/verify, lift/clear, transport/release and retreat through one guarded executor, using only permitted observations.
3. **Adaptive delegation:** calibrate policy reliability on development cases; compare direct-only, policy-only and routed execution on held-out pairs. Fallback after irreversible actions cannot guarantee non-regression.
4. **Matched-quality efficiency:** event-triggered review, stable context prefixes and bounded calls; measure latency, tokens, cache use and valid coverage under comparable budgets/hardware.
5. **Portable backends:** separate local/scheduler/cluster transport from episode semantics, with readiness, ownership, cleanup and non-replay conformance tests.

Each PR records hypothesis, owner, method ID, frozen cases, one changed variable, stopping criteria, evidence location and known failures. Do not tune on the final panel. Submit focused pull requests with tests and reproducible evidence.
